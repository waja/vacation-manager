# Vacation Manager

A small, non-interactive command-line tool for managing Dovecot/Pigeonhole Sieve vacation responders.

The tool generates and validates Sieve scripts for configured email addresses and installs them in the appropriate locations. It is designed to work with Froxlor-managed systems but is not limited to Froxlor.

## Status

The project is under development. Requirements and implementation plans are tracked in [GitHub Issues](https://github.com/waja/vacation-manager/issues).
