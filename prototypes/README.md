# Language prototypes

These small proofs of concept are not the vacation-manager implementation. They test two high-risk operations before committing to a language:

1. Quote a single-line value as a Sieve quoted string.
2. Publish a prepared file atomically without replacing an existing destination.

Bash is included as a familiar shell-based candidate; Python is included as the current repository direction and uses only the standard library. Go is included to evaluate single-binary deployment. Perl remains a secondary option.

## Run

Requirements: Bash 4+, GNU/Linux utilities, Python 3.10+, Go 1.22+, and no mail server.

```bash
bash prototypes/bash/test.sh
python3 -m unittest discover -s prototypes/python -v
(cd prototypes/go && go test ./...)
```

The tests use temporary directories. They cover quotes, backslashes, rejection of control characters, Unicode, successful installation, mode preservation, refusal to replace an existing file or symlink, and a missing destination directory.

## Sieve compiler compatibility

GitHub Actions runs the language tests and checks Sieve compiler compatibility against Debian 12, Debian 13, and Ubuntu 24.04. The compiler test compiles a valid fixture and confirms that an invalid fixture is rejected. Compiler output is directed to a disposable temporary directory, never the repository or a managed destination.

Run the compiler check locally on a Debian/Ubuntu host with Docker installed:

```bash
docker run --rm -v "$PWD:/workspace:ro" debian:trixie sh -eu -c '
  apt-get update
  apt-get install -y --no-install-recommends dovecot-sieve
  tmp=$(mktemp -d)
  trap "rm -rf \"$tmp\"" EXIT
  sievec /workspace/tests/sieve/valid.sieve "$tmp/valid.svbin"
  if sievec /workspace/tests/sieve/invalid.sieve "$tmp/invalid.svbin"; then
    echo "Invalid fixture unexpectedly compiled" >&2
    exit 1
  fi
'
```

This is a compiler compatibility smoke test, not yet a test of scripts generated by any prototype: none of the prototypes implements the full vacation-script generator yet.

## Important limitations

- None of the prototypes is a complete CLI, config parser, date/time implementation, or vacation-script generator.
- The quote helpers intentionally accept only single-line strings and reject control characters. Message bodies need a separate Sieve `text:`-block strategy.
- The install helpers use a hard link as the atomic no-replace publication primitive. The temporary file is created in the destination directory to keep it on the same filesystem. Filesystems that disallow hard links will fail safely rather than fall back to a racy check-then-move.
- Ownership, ACLs, SELinux labels, symlinked parent directories, and adversarial path races still need a deliberate production policy.
- Do not use these helpers in production yet.
